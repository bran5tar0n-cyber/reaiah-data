# King James Version (1769)

`KJV.json`: the 66-book Protestant canon, 31,102 verses, in the same shape as the other Reaiah Bibles (`{translation, books:[{name, chapters:[{chapter, verses:[{verse, text}]}]}]}`), with BSB book names so references line up.

- Source: `eng-kjv.osis.xml` from [seven1m/open-bibles](https://github.com/seven1m/open-bibles) at commit f257a3559025c3f873b48a75019f53a9354ed7de, listed there as public domain.
- Converted by Reaiah: notes removed, KJV italic (supplied) words kept as plain text, Apocrypha left out.
- License: public domain in the United States. (In the United Kingdom the KJV is under Crown patent.)
