# Word of the day pool

`pool.json`: 415 verse references (no Bible text) that Reaiah draws each person's random word of the day from. The app takes the verse text from its stored BSB.

- Chosen for a daily word: peace, love, wisdom, worship, hope, strength, faith, grace, rest, guidance, joy, mercy, courage. Spread across the Old and New Testaments.
- Left out on purpose: verses that only make sense in context or stop mid-sentence, verses aimed at one life situation (parents, marriage), and seasonal verses.
- Every reference is checked against `kjv/KJV.json` by `build_pool.py`.
- References are facts, not copyrighted text. License: public domain (CC0).
